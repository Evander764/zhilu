# 任务
受众：黑客松演示参与者与接手开发的同事。载体：在线 Web，桌面 1440×900，移动 390×844。目标动作：推荐浏览 → 详情阅读 → 登录收藏 → 设置管理。不可删：三页、真实登录、按用户隔离的数据。P0：问题与阅读正文，P1：收藏/关注/登录，P2：演示说明。

# 视觉方案
用户明确要求 1:1 复刻，使用当前知乎桌面页面为唯一视觉方向。浅灰背景 #f5f6f9、白色卡片、蓝色 #356dff、正文 #191b1f、说明 #8491a8；系统黑体标题与正文，数字沿用系统无衬线字体。推荐信息流、详情全宽题头加阅读栏、设置三栏是三种不同原型。
基线：忠实复刻，选用。策略候选：加大字号留白，会偏离原站，拒绝。过载反例：大横幅渐变装饰和路径图，会抢走问题层级，拒绝。用户固定方向，因此不额外做无关的三套视觉稿。

# 网格
顶部 62px；内容 1000px，694px 主栏 + 10px 间隔 + 296px 侧栏。标题 18px/1.6，正文 15px/1.7，详情 16px/1.9。设置 726px 主区 + 264px 帮助栏，主区内 164px 分类。移动 760px 断点转单栏，导航保留推荐、热榜、搜索、账号；操作保留收藏和分享。不得出现水平溢出或悬浮操作遮盖正文。

# 决策
实测知乎首页、答案详情和设置页，截图仅在浏览器临时缓存观察。登录沿用妙搭 SDK，身份仅来自可信网关，数据库按 app.user_id 行级隔离。原创演示正文和计数与知乎真实数据明确区分。旧知路保持 /map 与 /read。功能预留按钮弹窗说明未开放，不伪装完成。
