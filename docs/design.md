# 设计决策

读者在教程与实践之间卡住。第一眼识别自己的处境，第二眼看到一条有理由的去路，第三眼可以核对原文。首页用一句具体困惑建立重心；右侧展示实际可走的短路径；阅读时正文占主要宽度，来路与下一步辅助定位。

使用 aesthetic-layout 方法完成信息层级、同内容三方向比较和远中近检查。蓝色只标记可操作路径与当前重点；编辑导读使用中文系统无衬线，原话用宋体并独立注明覆盖范围。没有装饰性动画，尊重减少动态设置。

三方向比较在同一 1440 × 900 首页上进行：普通文字与线框基线更安静，但不容易辨认“继续往下走”；现方案放大困惑并用路径线连接下一问；高饱和、旋转和多重字号的反例会让摘录、步骤和标题争夺注意，未采用。比较截图保存在仓库外的验收目录。

手机将阅读改为单列，下一步接在正文之后；来路折叠，返回和分享可直接操作。来源索引和原文入口不隐藏在地图中。原生 dialog 提供键盘焦点范围和 Escape 退出。

目前是已做结构与浏览器检查的设计候选。真人审美认可、阅读帮助及真实学习效果均待实际试用，不能由截图和测试代替。
