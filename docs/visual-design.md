## 设计与阅读顺序

先选左栏入口，再沿中间地图发现问题；深绿只突出当前问题，白色节点保留上下文。箭头表达真实关系方向，走过的连接加深，检索关联保留虚线。点选节点后展开右侧阅读，来源摘录同步；收起阅读时重新适配全图，保留路径。

森林绿 #214f3a 承担当前状态，浅灰绿 #eff3ed 承担画布，白色承担阅读。苹方/系统无衬线承载界面与问题标题，宋体仅用于真实摘录。不加载外部字体，不虚构问题、原话、作者或关系。

主入口实际为 QuestionMapPage；/read 和旧路径链接仍进入 ZhiluPage，配色与 B 同步。改视觉前必须读 app.tsx 核对当前路由，不能以旧页面名推断主页。路径和来源使用现有数据/API。

## 桌面规则与验证

桌面左栏约 298px，阅读展开后约 265px；右侧阅读 410px。矮屏收紧纵向间距，左栏可独立滚动。地图监听实际画布宽高，收起阅读和改变窗口尺寸后重新适配。

React Flow 禁用元素选择时，会给节点设置 pointer-events:none；按钮必须显式恢复 pointer-events:auto。不能只验证节点存在：必须真实点击，并检查右栏标题、当前节点、来源和阅读轨迹同步。

本轮检查 1366×768、1440×1000、1920×1080 桌面。手机验收按用户要求暂缓。lint、44 项单元测试和生产构建通过。构建后完整重启 dev:local，再从实际首页回读。截图与交互证据保存在 ../deliverables/zhilu-b-desktop/。
