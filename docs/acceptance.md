## 三条试走路线

- 看懂以后：`practice → debug → feedback`。从改变一个例子，到描述预期与实际，再形成具体反馈问题。
- AI 做完以后：`ai → debug → feedback → practice`。先预测和解释，再检查差异，最后回到独立尝试。
- 报课之前：`paid → goal → practice`。先确定当前缺口，再说明完成条件，并做一次小尝试。

## 真人试用脚本（尚未执行）

请一位正在自学技能的成年人带着最近的真实卡点试用，无需注册，不要求提供私人作品或聊天记录。

1. 不解释界面，让对方自己选择一个入口。记录选了什么、花了多久、哪里犹豫；时间从实际观察获取。
2. 阅读一条导读，问“哪句来自原作者，哪部分是本站整理？”让对方打开原文入口，记录是否能理解覆盖范围。
3. 自己选择下一步，问“为什么现在看它？”对方能复述具体连接理由才算理解，点击次数不等于理解。
4. 返回、刷新并分享给自己的另一个窗口。检查能否找到来路；不收集对方完整搜索文字。
5. 合上网站，问“你接下来准备做哪一小步，怎样知道它有没有改善？”保留对方原话；说不出具体动作则视为路径仍需改进。
6. 与直接阅读一篇普通回答比较，询问网站是否减少了找下一步的困难，或只是增加了阅读负担。允许结论为没有帮助。

真人尚未验证：主题是否切中真实需求、连接是否有价值、审美是否认可、是否改善学习效果。无测试者联系、群消息或赛事提交。
