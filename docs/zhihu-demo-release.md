## 本轮发现并封住的问题

1. SDK 数据库角色为 `authenticated_<schema>`，不继承全局 `authenticated`。按实际角色创建策略，并通过临时双身份 SQL 测试验证。
2. Nest Controller 返回裸 `null` 会成为空文本响应，前端把它当账号对象后导致白屏。改为始终返回 `{account}`，新增控制器回归和 `scripts/zhihu-demo/verify-online.mjs` 正式站检查，确保未登录响应可解析为 JSON。
3. 线上环境禁止直接 DDL。先预览并迁移开发库结构；预览中旧问题索引函数差异经现场对比仅为空白格式，没有其他语义变更。

构建/测试脚本及后续接入位置见 `zhihu-demo-handoff.md`。回退首页时保留个人数据表，不能删除用户已经保存的记录。
