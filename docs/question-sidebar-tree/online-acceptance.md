# 候选上线后的操作验收

当前所有项目均待线上执行。协调任务先验证同一第 6 组应用的候选提交已部署，记录 release、commit、时间和页面地址。浏览器只复用已交接的 ego-browser space 32、p1，完成全部操作后由最终操作者 finish；不得新开空间、换组织或接管用户。截图与原始证据留在外部目录，不进 Git。

| 范围 | 操作与必须读回的结果 |
|---|---|
| 来源与接口 | 新 related 端点错误输入返回 400；真实标题返回 200、非空问题/回答或文章；再搜相同标题 cached=true。记录全部来源的类型和编号对应，确认没有无来源全文。 |
| 1468×715 | 打开 learning-with-ai；与 baseline.png 比对。正文 article 宽度 694px、9 个正文段落、正文文本一致。记录展开、收起、重开的 article x/width 与 scrollY，差值应为 0。 |
| 1024px | 展开/关闭仍沿用该断点原主栏尺寸。主栏、题头、侧栏和最长标题无水平溢出。 |
| 390px | 初始正文正常阅读，相关问题按钮可见且不盖回到顶部按钮；打开抽屉、滚动树、关闭，正文 width/scrollY 不变。页面和抽屉无水平溢出。 |
| 导航闭环 | 点击真实相关问题，页面标题和 URL 编号切换，下一次请求仅该题标题；来源回答能展开并打开真实知乎原文；浏览器后退恢复原问题与滚动位置。冷打开复制的相关问题 URL 也会检索，加载期间显示等待态。 |
| 关闭后换题 | A 收起→点继续阅读 B，B 自动检索；手机关闭抽屉→另选 B，B 自动检索且不自动弹出遮挡。A 同题关闭期间没有重试/轮询。 |
| 快速换题 | 慢响应条件下快速 A→B，A 的成功/错误都不能覆盖 B；不自动预抓子问题。 |
| 键盘 | Tab 可到问题、回答 disclosure、来源及收起/重开；Enter/Space 能展开回答；手机焦点留在抽屉，Esc 关闭后返回触发按钮；桌面 Esc 收起后焦点回到标题按钮。 |
| 账号回归 | 旧 smoke 的六篇、account=null、5 类个人接口匿名 401 仍通过；外部问题编号不进入个人数据 API。原作者信息仍能访问。 |
| 最终接受 | 以上通过只证明操作与结构。用户对正文阅读、侧栏密度与手机遮挡的主观接受单独记录；执行者不得自己放行。 |
