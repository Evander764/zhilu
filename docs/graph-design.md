# 问题图谱设计与实施约束

状态：制作中；公开体验候选，真人审美与使用价值待验证。

## 视觉哲学：在问题之间留下路

对象是正在知乎寻找答案的人。第一眼应识别当前问题与可走分支，选中后阅读真实作者的内容。图谱承担方向，阅读栏承担理解，底部轨迹承担回看。拒绝以学习分类卡片替代问题图形，拒绝随机漂移、满屏标签、自动生成回答。

P0：真实问题标题、当前节点、展开与阅读。P1：来路、来源、连接依据。P2：作者、日期、片段范围、分享与保存状态。错误路径：把相似检索结果理解成已验证的因果关系。以虚线和“检索关联”文字共同防止误读。

画布 #f7f9fc；正文 #202d42；焦点 #245ad6；辅助 #64748b；线条 #c4cedd；阅读底色 #ffffff。字号：品牌 24，阅读问题 26，节点 17，正文 15，辅助 12；系统中文无衬线，短摘录使用宋体回退。8px 间距基础；节点宽 248px，列距 340px，行距 200px。阅读侧栏 360px；小屏使用底部面板。所有文字横排，无图片、肌理或外部字体资源。

签名元素是焦点问题左侧的蓝色竖线，以及沿探索路径连续的蓝色曲线。选中、已访问、检索发现使用文字和线型区分，颜色不是唯一信息。

## 三方向对照

同一真实内容与 1440×960 画面：清晰基线使用朴素边框与相同线权；候选突出当前节点、路线与阅读栏；过载反例增加饱和底色、粗线与重阴影。比较在本地设计对照入口完成，不把反例发布为默认界面。内容与结构不随方向删减。
